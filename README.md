# 🚨 ResQMe – Emergency Contact Assistant

**ResQMe** is a PWA that makes your critical medical info and emergency contacts instantly accessible via QR code—especially when you can’t speak for yourself.

## ✨ Features

- 🩺 Store medical info (conditions, allergies, medications)  
- 📞 Save emergency contacts  
- 🔗 Share via scannable QR code  
- 🌐 Public view (no login needed)  
- 📱 Offline-ready & installable (PWA)  
- 🤖 Built-in AI chatbot  
- 🌍 Multi-language support
  
## 🛠 Tech Stack

React · TypeScript · Vite · Tailwind CSS  
shadcn/ui · QRCode.react · OpenAI · i18next · PWA

## 🚀 Quick Start

```bash
git clone <YOUR_GIT_URL>
cd resqme
npm install
npm run dev
```
